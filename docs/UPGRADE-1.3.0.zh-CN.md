# v1.3.0 · 框选、自动滚动与层级修复

2026-09-18。v1.3.0 正式发布版本。

## 对应截图的修复

### 右栏遮住最右列

原实现同时使用固定覆盖式右栏和拖拽前冻结的网格宽度；框选产生选中项后，右栏在拖拽途中打开，造成最右列仍按旧宽度排布却被覆盖。

- 首次框选过程中不弹出批量面板，松手后才展示，避免改变正在命中的图片位置。
- 若开始下一次框选前面板已打开，拖拽期间保持既有面板布局。
- 桌面为右侧面板保留 320px 实际空间，不再仅靠大屏 padding 补偿；覆盖 961–1279px 的旧空档。
- 窄屏改为预留空间的底部面板，图库与操作面板独立滚动，而非覆盖最右侧图片。

### 向下拖拽不滚动

原应用只有最小高度，整个文档可能被撑高；自动滚动却一直操作 `.ue-main-shell`，其底边可能处于屏幕之外。

- 应用高度约束为当前视口；图库拥有明确的独立滚动区域。
- 鼠标停在可见区域下沿/上沿时持续滚动，不需要不断移动鼠标。
- 边缘滚动速度有上限；鼠标捕获绑定稳定的主滚动容器，避免虚拟卡片卸载影响拖拽。
- 选框起点随内容滚动，命中计算与显示保持一致。
- 缩小选框会移除当前几何范围外的图片；Ctrl/Command 仍可保留此前选择并追加。
- 松手、Esc、失去窗口焦点或窗口尺寸变化会结束框选。Esc 沿用清除选择的行为，不是文件操作撤销。

### 下拉被左侧栏挡住

原顶栏 z-index 30，桌面侧栏 32，窄屏侧栏 50。只提高下拉自身层级不能越过父级层叠上下文。

现在顶栏整体位于桌面及窄屏侧栏之上，同时低于确认对话框、教程等模态层。浏览器测试不只判断可见，而是在菜单按钮左侧实际做 `elementFromPoint` 命中检查。

### 样式和可理解性

框选遮罩改为低透明度灰色，选中图片使用单层中性边框，移除蓝色标题、预览按钮及批量面板的蓝色渐变。批量操作提供文字标签，并检查文字不被固定宽度按钮裁切。删除操作保留红色危险提示。

## 安装与回退

安装包包含源码与编译前端，无需自行构建。先退出 ComfyUI，备份插件目录、实际生效的数据目录（包括 `UNIVERSAL_EXTRACTOR_DATA_DIR`）及图片。替换代码时不要覆盖自己的 `data`，旧插件备份放到 `custom_nodes` 外；重启并强制刷新浏览器。

本轮不迁移图片或工作流数据。回退需退出 ComfyUI 后恢复备份代码和对应数据。源码补丁为相对上游 `87960b0` 的累计补丁，不要直接叠加到 RC3 工作树；通常直接使用安装包更简单。
