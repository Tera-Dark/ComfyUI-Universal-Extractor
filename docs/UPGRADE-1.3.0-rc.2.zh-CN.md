# RC2 · 交互修订与升级说明

版本：**1.3.0-rc.2** · 2026-09-18。本地候选版本，未向上游推送或发布。

## 本轮具体修改

1. **黑块按钮**：引导按钮直接指定深底白字，不再依赖通用按钮样式继承。主操作按钮一并检查。
2. **跟随目标的新手引导**：11 步聚光高亮，浮窗根据目标位置和自身实际大小选择方向；切换工作区、展开侧栏、滚动和尺寸变化会重新定位。缺少图片或词库时显示解释，仍能继续。支持上一步、跳过、Esc、焦点循环；矮屏优先让说明内容滚动，而不是盖住目标。
3. **密度选择**：宽松 3 / 适中 4 / 紧凑 6 三个示意预设，另有 3–8 滑块和加减微调。沿用原列数偏好，窄屏实际列数可能更少。手机工具栏允许换行，避免互相遮挡。
4. **工作区描述**：图库、词库、工作台、设置均显示名称和一句用途说明，手机不再只剩图标。
5. **全局动效整理**：统一短淡入与颜色反馈，移除 `transition: all` 和整层图片查看器的位移动画；图片背景改成稳定深色，不再放大模糊原图。大图加载、解码成功后才换图，取消过期请求，预载相邻图片；加载失败可以重试。双击缩放使用短过渡，滚轮和拖拽保持直接反馈，关闭有短淡出。CSS 与 JS 滚动/关闭均尊重系统“减少动态效果”。
6. **国际化**：双栏目录文案集中到字典；补齐删除确认、筛选、LoRA 权重、重试等文案；日期使用当前语言，页面 `lang` 随语言更新。增加 833 个翻译键、占位符对齐和静态调用检查，并纳入 `npm run verify`。

没有更改图片存储格式、工作流格式或 RC1 后端保护机制。完整 RC1 后端改动与限制见 [RC1 升级说明](UPGRADE-1.3.0-rc.1.zh-CN.md)。

## 安装 / 从 RC1 升级

1. 退出 ComfyUI。备份当前插件目录、实际生效的 `data` 目录，以及图片目录。若设置过 `UNIVERSAL_EXTRACTOR_DATA_DIR`，务必备份该路径，不能只备份插件内的 `data`。
2. 解压安装包。包内包含完整源码和生产前端 `gallery_ui/dist`，普通安装**不需要 Node.js 或重新构建前端**。
3. 用新代码替换现有插件代码；先保存、再还原自己的数据与配置。不要用包内示例 `data` 覆盖自己的词库、图片状态或日志。旧插件备份放到 `custom_nodes` 外，避免两份插件被同时加载。
4. 用运行 ComfyUI 的 Python 环境执行 `python -m pip install -r requirements.txt`，然后重启 ComfyUI。
5. 浏览器强制刷新图库页面。若仍看到旧界面，清理该站点缓存；不要删除图片或真实数据来“清缓存”。
6. RC1 已完成引导的用户不会被强制重新引导。请到**设置 → 新手教程**重新播放，检查高亮、密度和工作区描述。
7. 先在副本/小图库试用搜索、详情、移动、垃圾箱恢复，再接入正式图片目录。

回退：退出 ComfyUI，恢复已备份插件代码和对应数据。不要在仍有未解决恢复日志时继续写操作。保留实际图片备份，日志补偿不等同于数据库事务。
