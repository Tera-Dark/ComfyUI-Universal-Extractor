# RC3 · 全局界面统一与 QoL 修订

2026-09-18 · 本地候选版本，未推送上游。以 RC2（`77fcb7a`）为基础；保留此前后端保护、图片加载与引导改进。

## 以图库为准统一页面，而不只是换色

- **工作台**：统一标题、字号、输入框和主次按钮；工具选择改为横向导航，移除推广式状态块；生成/复制显示文字；格式转换折叠为可选操作。灵感页去除占据首屏的统计大卡。
- **设置**：改为紧凑偏好列表，取消蓝色选中大卡；增加偏好/目录/诊断分区跳转；资源列表、编辑器、诊断与图库共用中性表面和操作样式。
- **词库、变体、双栏、筛选**：统一标题层级、边框、圆角和选中状态。错误、警告及实际色系筛选仍保留有意义的区别。
- 工作台在当前页面会话中保留参数、预选内容和结果草稿，切换到图库再回来不再全部重置；隐藏时用 React Activity 暂停 effect。**刷新页面/关闭浏览器不保证恢复这些草稿**。

## 双栏整理：安全高效优先

- 左右目录请求独立编号，迟到响应不能覆盖较新的目录内容。
- 增加“加载更多”，不再只能操作首次加载的 80 张；明确显示已加载/总数，全选只作用于已加载图片。
- 双栏独立读取目录，不继承图库搜索/筛选；隐藏不生效的上方浏览控件，并提供明确的“返回图库”。
- 移动前确认数量、来源、目标；从确认到完成锁定重复移动，处理期间禁用目录表单控制。
- 使用服务器已有的冲突安全处理，不直接覆盖同名文件；结果持久显示已移动、未找到、被阻止数量。
- 请求失败保留选择，部分失败保留对应项。没有新增“自动删除重复图”或未经验证的撤销承诺。

## 变体与筛选

- 变体提供**已加载分组**搜索，以及最近更新/图片数量/规则得分排序；不修改原始数组。
- 显示分组筛选数量、明确返回图库，并补充“相似、同提示词、同工作流不代表可以安全删除”的说明。
- 变体请求添加过期结果保护，防止快速切换时显示旧分组。
- 清除筛选不再偷偷恢复排序；默认排序单独重置。筛选面板支持 Esc 关闭并回焦触发按钮。
- 分组查询仍沿用服务器每次最多 120 组的现有接口；此处搜索不是全库搜索，不是完整的新重复文件管理器。

## 设置与通用保护

- 修复“添加自定义目录”被自动跳回默认资源的问题。
- 来源设置显示未保存状态；切换资源、切换工作区、从侧栏打开词库时先确认；取消后保留输入。
- 外部来源刷新不再覆盖正在编辑的草稿；浏览器离开时注册未保存提示。
- 保存要求名称、路径非空；服务端继续负责真实路径/权限校验。
- 统一确认框改为 portal 模态层：底层 inert、安全取消按钮初始焦点、Tab 循环、Esc 取消、关闭回焦。新的确认替代旧确认时，旧调用安全返回取消，不悬挂。

## 安装

安装包包含源码与生产前端，普通使用无需 Node.js。

1. 退出 ComfyUI，备份插件、实际生效的数据目录和图片目录。设置过 `UNIVERSAL_EXTRACTOR_DATA_DIR` 时须备份该路径。
2. 替换插件代码，**不要用包内示例数据覆盖自己的 `data`**；旧插件备份放在 `custom_nodes` 外，避免重复加载。
3. 使用 ComfyUI 的 Python 环境运行 `python -m pip install -r requirements.txt`，重启后强制刷新图库。
4. 先在小图库副本测试移动、筛选和资源设置。RC3 不需要迁移数据或修改现有工作流。

回退时退出 ComfyUI，恢复备份代码与对应数据。日志补偿不是 ACID 数据库，不能替代真实图片备份。更早的后台限制见 RC1/RC2 升级说明。
